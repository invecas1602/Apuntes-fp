# Anexo I

### Resumen de etiquetas HTML

Ordenadas de mayor a menor uso

|Etiqueta|Uso|
|---|---|
|<html>|Define el documento como HTML.|
|<head>|Contiene metadatos y enlaces a scripts, hojas de estilo, etc.|
|<title>|Define el título de la página que aparece en la pestaña del navegador.|
|<body>|Contiene el contenido principal visible en la página web.|
|<h1> - <h6>|Encabezados de diferentes niveles (1 es el mayor, 6 el menor).|
|<p>|Define un párrafo.|
|<a>|Crea un enlace a otra página o recurso.|
|<img>|Inserta una imagen.|
|<ul>|Crea una lista desordenada.|
|<ol>|Crea una lista ordenada.|
|<li>|Define un elemento de una lista.|
|<dl>|Crea una lista de definición.|
|<dt>|Define un término en una lista de definición.|
|<dd>|Define una descripción para un término en una lista de definición.|
|<div>|Define un contenedor genérico para contenido en bloque.|
|<span>|Define un contenedor genérico para contenido en línea.|
|<table>|Crea una tabla.|
|<tr>|Define una fila de una tabla.|
|<td>|Define una celda dentro de una fila.|
|<th>|Define una celda de encabezado de tabla.|
|<caption>|Proporciona un título para una tabla.|
|<thead>|Agrupa el contenido del encabezado de una tabla.|
|<tbody>|Agrupa el contenido del cuerpo de una tabla.|
|<tfoot>|Agrupa el contenido del pie de una tabla.|
|<form>|Crea un formulario para entrada de datos.|
|<input>|Define un campo de entrada en un formulario.|
|<button>|Crea un botón interactivo.|
|<label>|Define un texto asociado a un control de formulario.|
|<fieldset>|Agrupa elementos dentro de un formulario.|
|<legend>|Proporciona un título a un grupo de controles en un formulario.|
|<select>|Crea un menú desplegable.|
|<option>|Define un elemento dentro de un menú desplegable.|
|<textarea>|Define un área de texto multilínea.|
|<header>|Define un encabezado para una sección o página.|
|<footer>|Define el pie de página de una sección o página.|
|<article>|Define contenido independiente y autónomo.|
|<section>|Define una sección temática.|
|<nav>|Define un bloque de navegación.|
|<aside>|Define contenido secundario o complementario.|
|<main>|Define el contenido principal de una página.|
|<strong>|Define texto con énfasis fuerte (generalmente negrita).|
|<em>|Define texto enfatizado (generalmente cursiva).|
|<br>|Inserta un salto de línea.|
|<hr>|Inserta una línea horizontal para separar contenido.|
|<code>|Define fragmentos de código.|
|<pre>|Define texto preformateado.|
|<blockquote>|Define una cita en bloque.|
|<cite>|Define el título de una obra o fuente citada.|
|<abbr>|Define una abreviatura o acrónimo con información adicional.|
|<address>|Proporciona información de contacto.|
|<b>|Define texto en negrita.|
|<i>|Define texto en cursiva.|
|<small>|Define texto en tamaño más pequeño.|
|<sup>|Define texto como superíndice.|
|<sub>|Define texto como subíndice.|
|<mark>|Resalta texto con color de fondo.|
|<time>|Define una fecha u hora específica.|
|<progress>|Representa el progreso de una tarea.|
|<meter>|Representa un valor dentro de un rango conocido.|
|<audio>|Inserta contenido de audio.|
|<video>|Inserta contenido de video.|
|<source>|Define fuentes adicionales para <audio> y <video>.|
|<iframe>|Inserta otro documento dentro del documento actual.|
|<svg>|Define gráficos vectoriales escalables.|
|<canvas>|Proporciona un área para gráficos mediante JavaScript.|
|<noscript>|Define contenido alternativo si JavaScript está deshabilitado.|
|<template>|Define un fragmento de HTML reutilizable.|
|<script>|Inserta código JavaScript o enlaza un archivo JS externo.|
|<link>|Vincula hojas de estilo externas u otros recursos.|
|<meta>|Define metadatos sobre la página (como codificación de caracteres).|
