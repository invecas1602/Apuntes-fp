# **4.1.3. Remote Desktop Protocol (RDP)**

El protocolo de escritorio remoto o RDP se utiliza, como el VNC, para conectarse con un ordenador remoto y abrir una sesión de escritorio en él. Al ser un sistema propietario de Microsoft, se utiliza principalmente para acceder a equipos basados en Windows para tareas administrativas, de soporte o teletrabajo.

Por defecto, el RDP utiliza el puerto 3389 para establecer una comunicación cifrada entre cliente y servidor, mediante la cual no solo es posible controlar un ordenador remoto, sino que también se puede acceder a todos sus recursos locales y de red: archivos, aplicaciones, impresoras e incluso el contenido del portapapeles.

Como en el caso del VNC, permite manejar múltiples sesiones de escritorio independientes, e incluye características para la optimización del ancho de banda. Para poder acceder al equipo remoto, este debe tener activada la característica de Escritorio remoto. La conexión se realiza, como es habitual, indicando la dirección IP o nombre de anfitrión remoto y unas credenciales válidas de acceso.
