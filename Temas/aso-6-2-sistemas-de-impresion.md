# **6.2. Sistemas de impresión**

Un sistema de impresión es el conjunto software y hardware que se utiliza para gestionar los trabajos de digitalización, copia, impresión o envío de documentos. Incluye los siguientes componentes:

- **Dispositivos de impresión**: según su conectividad y funcionalidad, pueden ser de tres tipos: una impresora local conectada directamente al ordenador (ya sea mediante cable o bien de forma inalámbrica), una impresora compartida en red o una impresora lógica.
- **Controladores de impresión**: software que proporciona la interfaz de comunicación entre el sistema operativo y la impresora, es decir, el componente encargado de traducir las órdenes de impresión del sistema a un lenguaje que la impresora sea capaz de entender, ya sea PostScript, PCL o cualquier otro.
- **Cola de impresión**: software que gestiona los procesos de impresión a través de una cola de trabajos. No solo controla la transmisión de los datos utilizando determinados protocolos y puertos, sino que programa y supervisa la ejecución de los trabajos de impresión enviados por los usuarios sin que interfieran entre sí.
- **Herramientas de gestión**: pueden incluir una interfaz de gestión y agrupación de impresoras, un sistema de contabilidad de trabajos de impresión, y funciones de filtrado y personalización de los trabajos.
