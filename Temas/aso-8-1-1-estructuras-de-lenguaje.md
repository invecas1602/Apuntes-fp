# **8.1.1. Estructuras de lenguaje**

![](_page_234_Picture_3.jpeg)

En un programa, las unidades básicas de ejecución del código se denominan **sentencias.** Las sentencias son las estructuras que sirven para realizar operaciones específicas o controlar el flujo del programa, pudiendo utilizar, para estos fines, otras estructuras. Por ejemplo, mediante una sentencia podemos asignar valores a otros elementos, como variables y funciones, o hacer que el programa ejecute un bloque de código u otro dependiendo de si se cumplen o no ciertas condiciones.

Además de las sentencias, las estructuras más comunes en los lenguajes de programación son las siguientes:

- **Variables**: se utilizan para almacenar datos en la memoria. Una variable siempre tiene un nombre y, dependiendo del lenguaje utilizado, un tipo de dato asignado: números (enteros, de coma flotante, etc.), caracteres (letras, símbolos, etc.) u objetos.
- **Expresiones**: combinaciones de variables, valores y operadores lógicos y aritméticos. Permiten realizar operaciones matemáticas y booleanas para evaluar los datos proporcionados y, a partir de ellos, generar un resultado.
- **Funciones**: bloques reutilizables de código que realizan tareas específicas a partir de ciertos parámetros o valores de entrada. Por lo general, las funciones realizan un determinado conjunto de operaciones sobre dichos parámetros y devuelven un resultado.
- **Estructuras de control**: sirven para controlar el flujo de ejecución del programa, bien mediante la repetición de bloques (los bucles), bien comprobando si se cumplen ciertas condiciones previamente establecidas.

En programación, las **estructuras de lenguaje** son los elementos que se utilizan para confeccionar un programa funcional a través de un código escrito. Cada lenguaje de programación posee su propio conjunto de estructuras, tanto semánticas (definen el significado de cada elemento), como sintácticas (determinan la forma en la que se organizan dichos elementos dentro del código).

- **Estructuras de datos**: permiten organizar y manipular conjuntos de datos con el fin de acceder a ellos y manipularlos de forma más eficiente que mediante el uso de variables individuales. Ejemplos de este tipo de estructuras son las matrices, las listas, las pilas y las colas. Algunos lenguajes permiten también crear estructuras de datos personalizadas.
- **Clases y objetos**: los objetos son estructuras propias de los denominados lenguajes de programación orientados a objetos, y las clases son los elementos que definen sus propiedades (atributos) y comportamientos (métodos).De hecho, los objetos son instancias de clases que pueden contener datos y realizar operaciones.
- **Bibliotecas**: colecciones de código que ofrecen funciones adicionales al lenguaje de programación, lo que permite a los desarrolladores aprovechar el código existente para realizar ciertas operaciones o tareas comunes.

Tanto los lenguajes compilados como los interpretados (incluyendo los lenguajes de *script*), pueden utilizar cualquiera de estas estructuras. No obstante, los tipos específicos y su sintaxis puede variar mucho de un lenguaje a otro, dependiendo de los paradigmas que se utilicen para organizar el código, y de los respectivos modelos de cómputo y ejecución de tareas.
