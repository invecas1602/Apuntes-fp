# Anexo III. Palabras reservadas

### JavaScript

Ordenadas de mayor a menor uso

|Palabra reservada|Uso|
|---|---|
|var|Declara una variable (uso antiguo, ámbito de función).|
|let|Declara una variable con ámbito de bloque.|
|const|Declara una constante de solo lectura con ámbito de bloque.|
|if|Ejecuta un bloque de código si una condición es verdadera.|
|else|Ejecuta un bloque de código si la condición en if es falsa.|
|switch|Ejecuta bloques de código dependiendo del valor de una expresión.|
|case|Define una condición dentro de un switch.|
|default|Define un bloque predeterminado en un switch si no se cumplen los casos anteriores.|
|for|Crea un bucle con una condición inicial, límite y paso.|
|while|Crea un bucle que se ejecuta mientras una condición sea verdadera.|
|do...while|Crea un bucle que ejecuta el bloque al menos una vez y luego evalúa la condición.|
|break|Detiene un bucle o una estructura switch.|
|continue|Salta a la siguiente iteración de un bucle.|
|function|Declara una función.|
|return|Sale de una función y opcionalmente devuelve un valor.|
|class|Declara una clase en ES6.|
|constructor|Declara un método especial dentro de una clase para inicializar objetos.|
|extends|Define una subclase que hereda de otra clase.|
|super|Llama al constructor o métodos de la clase padre.|
|this|Hace referencia al objeto actual en un contexto.|
|new|Crea una nueva instancia de un objeto o clase.|
|try|Define un bloque de código para manejar errores.|
|catch|Define un bloque para manejar errores que ocurren en el bloque try.|
|finally|Define un bloque de código que se ejecuta siempre, sin importar si hubo un error.|
|throw|Lanza un error definido por el usuario.|
|typeof|Devuelve el tipo de un operando (string, number, object, etc.).|
|instanceof|Verifica si un objeto es una instancia de una clase específica.|
|null|Representa un valor nulo intencionalmente asignado.|
|undefined|Representa una variable declarada pero no inicializada.|
|true|Representa un valor booleano verdadero.|
|false|Representa un valor booleano falso.|
|NaN|Representa un valor no numérico ("Not-a-Number").|
|Infinity|Representa un valor numérico infinito.|
|async|Declara una función que retorna una promesa y permite usar await.|
|await|Pausa la ejecución de una función async hasta que se resuelve una promesa.|
|Promise|Objeto para manejar operaciones asíncronas.|
|import|Importa funciones, objetos o módulos en ES6.|
|export|Exporta funciones, objetos o módulos para reutilizarlos.|
|yield|Pausa y reanuda una función generadora.|
|debugger|Detiene la ejecución de código en el depurador.|
|with|Ejecuta un bloque con un objeto específico como ámbito (uso desaconsejado).|
|delete|Elimina una propiedad de un objeto.|
|Object|Clase base de todos los objetos en JavaScript.|
|Array|Clase para manejar listas o colecciones ordenadas.|
|Math|Objeto que proporciona funciones matemáticas y constantes.|
|Date|Clase para manejar fechas y horas.|
|RegExp|Clase para manejar expresiones regulares.|
|JSON|Objeto para trabajar con datos en formato JSON.|
|console|Proporciona acceso a la consola del navegador (como log, warn, error).|
|alert|Muestra un cuadro de alerta al usuario.|
|document|Representa el documento HTML cargado en el navegador.|
|window|Representa la ventana del navegador.|
|localStorage|Almacena datos clave-valor en el navegador de manera persistente.|
|sessionStorage|Almacena datos clave-valor en el navegador para la duración de la sesión.|
|setTimeout|Ejecuta una función después de un retraso específico.|
|setInterval|Ejecuta una función repetidamente con un retraso fijo entre cada ejecución.|
|clearTimeout|Detiene una acción configurada con setTimeout.|
|clearInterval|Detiene una acción configurada con setInterval.|
