# Anexo II. Palabras reservadas

### Propiedades CSS

Ordenadas de mayor a menor uso

|Propiedad|Uso|
|---|---|
|clip-path|Define una ruta de recorte para un elemento, ocultando partes fuera de la forma especificada.|
|mask|Aplica una máscara a un elemento, controlando qué partes son visibles.|
|filter|Aplica efectos gráficos como desenfoque, brillo o contraste a un elemento.|
|backdrop-filter|Aplica efectos gráficos al fondo detrás de un elemento (requiere transparencia).|
|scroll-behavior|Define el comportamiento de desplazamiento para anclas (auto, smooth).|
|overscroll-behavior|Controla el comportamiento del desplazamiento al llegar al límite del contenedor (none, contain, auto).|
|aspect-ratio|Establece una relación de aspecto para un elemento.|
|object-fit|Define cómo se ajusta una imagen o video dentro de su contenedor (contain, cover, etc.).|
|object-position|Establece la posición de una imagen o video dentro de su contenedor.|
|isolation|Establece un nuevo contexto de apilamiento para un elemento (auto, isolate).|
|perspective|Define la distancia de visión para transformaciones 3D.|
|perspective-origin|Define el punto de origen para una transformación 3D en perspectiva.|
|transform-origin|Establece el punto de origen para transformaciones 2D o 3D.|
|content|Inserta contenido generado (usado en ::before y ::after).|
|columns|Define el número y ancho de las columnas en diseño de texto multicolumna.|
|column-gap|Define el espacio entre columnas en diseño multicolumna.|
|column-rule|Define el estilo de la línea entre columnas.|
|caret-color|Define el color del cursor de texto (caret).|
|writing-mode|Establece la dirección del texto (horizontal-tb, vertical-rl, etc.).|
|text-overflow|Controla cómo se maneja el texto desbordado (clip, ellipsis).|
|line-clamp|Limita el texto a un número específico de líneas, con truncamiento si es necesario (requiere overflow: hidden).|
|user-select|Controla si el texto puede ser seleccionado por el usuario.|
|pointer-events|Define si un elemento puede responder a eventos del puntero (none, auto).|
|resize|Permite o restringe el cambio de tamaño de un elemento (none, both, horizontal, vertical).|
|will-change|Indica qué propiedades cambiarán próximamente para optimizar el rendimiento.|
|place-content|Combinación de align-content y justify-content para contenedores flex o grid.|
|place-items|Combinación de align-items y justify-items.|
|place-self|Combinación de align-self y justify-self.|
|grid-auto-flow|Controla cómo se colocan los elementos automáticamente en un contenedor grid (row, column, dense).|
|grid-auto-columns|Define el ancho de las columnas creadas automáticamente en un grid.|
|grid-auto-rows|Define la altura de las filas creadas automáticamente en un grid.|
|align-content|Alinea el contenido de un contenedor flex o grid cuando hay espacio extra.|
|align-self|Alinea un elemento específico dentro de su contenedor flex o grid.|
|justify-self|Alinea un elemento específico horizontalmente dentro de su contenedor grid.|
|animation-name|Define el nombre de la animación aplicada.|
|animation-duration|Establece la duración de una animación.|
|animation-timing-function|Controla el ritmo de la animación (ease, linear, ease-in, etc.).|
|animation-delay|Especifica el tiempo antes de que comience una animación.|
|animation-iteration-count|Define cuántas veces se repite una animación.|
|animation-direction|Controla si la animación se reproduce hacia adelante, atrás o alterna (normal, reverse, alternate).|
|animation-fill-mode|Define el estado de un elemento antes y después de que se reproduzca una animación (forwards, backwards).|
