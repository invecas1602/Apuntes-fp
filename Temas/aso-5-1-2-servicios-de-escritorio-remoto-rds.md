# **5.1.2. Servicios de Escritorio remoto (RDS)**

Los Servicios de Escritorio remoto, también conocidos como RDS (del inglés *Remote Desktop Services*), son el método que integra Windows Server para proporcionar acceso, por usuario o por grupo de usuarios, a las aplicaciones instaladas en el servidor.

Estas son algunas de las ventajas de utilizar el Escritorio remoto para servir aplicaciones:

- **Integración con el Directorio Activo**: ofrece una administración centralizada del directorio y de las aplicaciones a disposición de los usuarios del dominio.
- **Acceso web**: Windows Server integra el rol de servidor web, lo que permite proporcionar acceso a las aplicaciones, desde cualquier lugar con conexión a Internet usando un simple navegador.
- **Experiencia de usuario consistente**: los usuarios pueden conservar las configuraciones de aplicación personalizadas y acceder a una misma versión de la aplicación desde cualquier dispositivo.
- **Seguridad reforzada**: además de los mecanismos de seguridad integrados a nivel de dominio para la autenticación, autorización y la transmisión de datos, solo los usuarios autorizados tienen acceso a las aplicaciones y a la información confidencial almacenada en el servidor.
- **Reducción de costes**: servir aplicaciones de forma centralizada puede abaratar el gasto de la organización en licencias de software y en adquisiciones de hardware.
