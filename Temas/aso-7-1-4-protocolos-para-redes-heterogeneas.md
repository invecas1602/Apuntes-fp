# **7.1.4. Protocolos para redes heterogéneas**

En los entornos de red heterogéneos mixtos, resulta fundamental optar por protocolos estándar que garanticen no solo la interoperabilidad de los equipos que los componen, sino también que las comunicaciones sean lo más fluidas y seguras posible. Entre los protocolos de uso común para la integración de sistemas libres y propietarios, se cuentan los siguientes:

- **TCP/IP**: es el conjunto de protocolos que, universalmente, se utiliza hoy para las comunicaciones en red, tanto locales (LAN) como de área amplia (WAN), lo que incluye cualquier tipo de intranet o extranet, así como Internet.
- **HTTP/HTTPS**: el HTTP se utiliza en Internet para transmitir documentos web basados en hipertextos, aunque permite también la transferencia de archivos y otros recursos. El HTTPS es la versión segura del protocolo, que añade cifrado SSL/TLS a las comunicaciones.
- **DNS**: es el protocolo que se utiliza para traducir nombres de dominio a direcciones IP y viceversa, por lo que es esencial para configurar los accesos a sitios web, servidores de correo o de archivos y cualquier otro servicio dentro de un dominio.
- **SNMP**: se emplea para la gestión de las redes, incluyendo la supervisión de los dispositivos y los recursos compartidos, la monitorización de su rendimiento y el estado general de la red.
- **DHCP**: protocolo para la configuración dinámica de anfitrión, es decir, la asignación automática de direcciones IP y otros parámetros de configuración de red a los dispositivos que se conectan al entorno heterogéneo.
- **SSH**: proporciona acceso remoto seguro a los dispositivos desde una interfaz de línea de órdenes, facilitando así su administración remota.
- **SFTP**: protocolo basado en el SSH para la transferencia segura de archivos.
- **SMTP/IMAP**: protocolos para el envío y la recepción de mensajes de correo electrónico.
